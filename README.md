# ⚙️ Automação de Sistemas e Processos com Python

Estudos de automação de tarefas e processos usando Python em **Jupyter Notebook**.

## Conteúdo

| Arquivo | Descrição |
|---|---|
| `primeira automação em python.ipynb` | Minha primeira automação em Python, desenvolvida passo a passo no notebook |

## Por que automação?

Venho da área de **Logística e PCP**, onde muitas tarefas são repetitivas: relatórios, planilhas e controles. Este repositório reúne meus estudos para automatizar esse tipo de processo com Python.

## Tecnologias

Python · Jupyter Notebook

## Como executar

```bash
pip install notebook
jupyter notebook
```

Depois, abra o arquivo `.ipynb` e execute as células em ordem.
